CSS Flexbox Complete Guide

Master flexbox layout with practical examples and exercises.

25 min read

Flexbox is a one-dimensional layout model that makes it easy to distribute space and align items in a container. It's the go-to solution for most layout challenges.

Flex Container Properties

css
.container {
  display: flex;
  flex-direction: row;      /* row | column */
  justify-content: center;  /* main axis alignment */
  align-items: center;      /* cross axis alignment */
  gap: 1rem;                /* space between items */
  flex-wrap: wrap;          /* allow wrapping */
}

Flex Item Properties

css
.item {
  flex: 1;           /* grow and shrink equally */
  flex-grow: 1;      /* how much to grow */
  flex-shrink: 0;    /* prevent shrinking */
  flex-basis: 200px; /* initial size */
  align-self: flex-end; /* override align-items */
}

Common Patterns

  • Centering — justify-content: center; align-items: center;
  • Navigation bar — justify-content: space-between;
  • Card grid — flex-wrap: wrap; gap: 1rem;
  • Sticky footer — flex-direction: column; min-height: 100vh;
